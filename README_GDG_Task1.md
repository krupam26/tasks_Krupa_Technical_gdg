# 🧠 GDG Task 1 — Exploratory Data Analysis (EDA)

## 📘 Overview
This notebook was created as part of **Google Developer Group (GDG) Task 1**, aimed at helping participants strengthen their understanding of **Exploratory Data Analysis (EDA)** in Python.  
It walks through the entire EDA workflow — from importing data and cleaning it, to visualizing insights and generating automated profiling reports.

## 🎯 Objectives
- Understand the purpose and process of EDA  
- Learn to clean, preprocess, and visualize datasets  
- Practice using Python’s data analysis libraries effectively  
- Generate an **automated data profiling report** with `ydata-profiling`

## 🧰 Libraries Used
- **pandas** – for data manipulation and analysis  
- **numpy** – for numerical operations  
- **matplotlib** – for plotting  
- **seaborn** – for statistical visualization  
- **ydata-profiling** – for automated EDA report generation  

## ⚙️ Setup Instructions
1. Clone or download this repository.  
2. Open the notebook in **Google Colab** or **Jupyter Notebook**.  
3. Install required dependencies:
   ```bash
   pip install ydata-profiling pandas numpy matplotlib seaborn
   ```
4. Run all cells sequentially.

## 📊 Features
- Step-by-step EDA explanation (from basic to advanced)  
- Data cleaning and visualization examples  
- Correlation and outlier detection plots  
- Automated profiling report generation  
- Insights derived using both manual and automated techniques
